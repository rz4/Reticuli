## New measured unforced dimensions (carve candidates)

1. **Mint-fold commutativity — promote.** M3's `mint_node` folds
   `list(children)` (order-sensitive); ours folds `sorted(...)`. The kernel
   clause only ever tests 0 or 1 children, so both pass — two honest kernels
   disagree on whether the mint is a function of the component *set* or
   *sequence*. Component enumeration order is not part of the claim, so the
   fold should be order-free: one assert
   (`mint_node(R,D,["a","b"]) == mint_node(R,D,["b","a"])`) separates every
   honest kernel from an order-fragile one at zero basin width.
2. **`realization_digest` from-exclusion — note, don't push.** M3's digest
   hashes every free-class output; ours excludes `from`-supplied bytes.
   Localization survives either way (the floor is still named by the lowest
   moved mint) — the difference is only whether an upper rung's digest
   describes its own work or also its inheritance. Weak candidate; the
   divergence rule doesn't clearly demand it.
